## 0.0.1

* Restyle dialogs, alerts, date and event popups, dropdowns, and snackbars. Add `LinnAlert.show` for modal feedback.

* Add `LinnThemeData.applyTo` for app-wide styling and `style` overrides on all 37 widgets.

* Add seven operational tables and five workflow controls. Number all 37 gallery entries.

* Add the read-only LinnCalendarView with Day, Week, and Month modes and event details.

* Add the calendar header, schedule slot, item selection row, quantity stepper, approval actions, and status dot.

* Add LinnSearchField, LinnFilterChip, LinnIconButton, LinnPagination, LinnSummaryCard, and LinnDialog.

* Adopt the Linn prefix for public widgets and LinnState. Retain deprecated Solar aliases.
* Add LinnDatePicker, LinnDataTable, and LinnSnackbar and their gallery previews.

* Add SolarDropdown, SolarCheckbox, and SolarStatusBadge with the same state API.
* Extend the gallery to preview six components with interactive selections.

* Add three Solar widgets with a shared state API.
* Add an interactive gallery and save/retry simulation.
* Add component and gallery behavior tests.
